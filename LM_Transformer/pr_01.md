## Selective Context Retention (SCR)

Long conversational agents must balance the need to retain relevant dialogue history
with practical compute and memory constraints. We propose **Selective Context
Retention (SCR)**, a learnable, token-level gating mechanism trained end-to-end using
a language modeling objective combined with a retention budget penalty.

The gating module softly decides which tokens should remain in the active context and
which can be dropped or moved into a compact memory representation. During training,
we apply a differentiable relaxation via **Gumbel-Softmax** to enable gradient flow
through the discrete retention decisions. A retention budget loss is added to
encourage the model to preserve task-relevant information while minimizing overall
context length.

We evaluate SCR on synthetic long-dialog tasks as well as subsets of **MultiWOZ** and
**DailyDialog**. Results show that SCR retains **50% or fewer tokens** while incurring
less than **2% loss in next-token prediction accuracy**, and significantly improves
throughput. To support reproducibility, we open-source a small **PyTorch** demo that
illustrates the approach.

## Problem and Motivation

Transformer-based attention mechanisms scale quadratically with context length, making
long, multi-turn conversations computationally expensive. As dialogue progresses,
earlier content often becomes irrelevant, yet naive truncation strategies can
significantly degrade model performance. This motivates the need for adaptive methods
that learn, on a per-conversation basis, which parts of the context are worth
retaining.
